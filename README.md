# Team Directory Tool
[![verify](https://github.com/AndiswaMbonambi08/team-directory/actions/workflows/verify.yml/badge.svg)](https://github.com/AndiswaMbonambi08/team-directory/actions/workflows/verify.yml)

A simple command line tool that reads a list of team members from a text file and lets you view all entries, count them, or search for someone by name.

## Requirements
Python 3 must be installed to run this tool.

## How to run
Run the script with:
python app.py
